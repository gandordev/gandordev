### [Bing Auto Search](https://github.com/gandordev/bing-auto-search)

A Python automation tool that performs configurable batches of web searches in Microsoft Edge using Selenium WebDriver.

**Key features:**
- Automated Bing searches using predefined keywords.
- Configurable number of searches.
- Randomized search terms and typing delays.
- Retry handling and automatic browser cleanup.
- Logging and failure management.

**Tech stack:**

### [AutoMovement](https://github.com/gandordev/AutoMovement)

A Windows desktop application that simulates keyboard and mouse input to automate repetitive actions in applications and games.

**Key features:**
- Simulated keyboard presses and mouse clicks.
- Configurable action durations and random intervals.
- Window selection to target input.
- Custom stop key and execution time limits.
- Optional automatic computer shutdown.

**Tech stack:**

### [Steam Review Generator](https://github.com/gandordev/steam-review-generator)

A lightweight web application for creating structured Steam game reviews and generating ready-to-use BBCode.

**Key features:**
- Customizable ratings and review categories.
- Support for custom categories.
- English and Spanish interfaces.
- Automatic BBCode generation and clipboard copying.
- Browser-based persistence using Local Storage.
- Automated deployment with GitHub Actions.
